# House Price Prediction Using Machine Learning

Beginner-friendly ML project that predicts house prices from area, bedrooms, bathrooms, and house age.

## Run
```bash
py -m pip install -r requirements.txt
py src/train.py
py -m streamlit run app.py
```

The included CSV is a small learning/demo dataset. For a stronger college project, replace it with a larger real-world dataset and retrain.
